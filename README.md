# 📊 Northwind Sales & Inventory Analysis (SQL Project)

📌 Project Overview  
This project analyzes the Northwind sample database to gain insights into sales performance, customer behavior, and inventory trends using SQL. The goal is to answer real business questions and support data-driven decision-making.

🎯 Objectives  
- Analyze total orders and revenue trends  
- Identify top-performing products and regions  
- Understand customer and order patterns  
- Track monthly sales trends  

🗂 Dataset  
Source: Northwind Sample Database  

Tables Used:  
- orders  
- order_details  
- customers  
- products  
- categories  

🛠 Tools & Technologies  
- SQL  
- Skillovilla SQL Playground  
- GitHub  

🔍 Key Analysis & Queries  
- Total orders by country  
- Top 10 most expensive products  
- Revenue by product/category  
- Regional sales performance  
- Monthly order trend  

All SQL queries are available in the `Queries.sql` file.

📈 Key Insights  
- Certain regions contribute significantly to total sales  
- A small number of products generate higher revenue  
- Orders show clear monthly trends useful for forecasting  

Detailed insights are documented in `Insights.md`.

📂 Project Structure  
Northwind-sales-inventory-analysis/  
│── README.md  
│── Queries.sql  
│── Insights.md  

🚀 How to Use  
1. Load the Northwind database into any SQL environment  
2. Run queries from `Queries.sql`  
3. Review insights in `Insights.md`
